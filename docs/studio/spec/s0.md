## 0 · 当前有效范围与决策

| 决策 | 唯一有效规则 |
| --- | --- |
| 商业身份 | 个人开发者商业发布、收费运营C端Studio；不是个人非商业研究。个人、独资或低营收不自动获得许可豁免；按1A/1B记录逐模型、版本、操作的真实许可事实，项目执行按1C默认allow_with_warning，不因商业许可缺口硬阻断。动态漫是可选用途，不替换专业图片/视频Studio定位。 |
| 媒体架构 | FFmpeg共享媒体底座＋共享NLE语义/调度/工程内核＋各端硬件适配。Dart负责文档、事务、UI与独立Harness；实时像素、采样、编解码在C++/平台层；Web独立实现MediaPort。商业SDK仅比较。 |
| 生成与会话 | P1包含按用途编译prompt、异步单镜头生成、多候选与可编辑多镜NLE。Session/Branch与TimelineRevision分离；本地上下文不依赖某个provider，多Agent可用不同端侧/云模型。候选不自动覆盖手工编辑。 |
| 持久化 | workspace是运行事件/投影真相，CAS保存不可变资源；工程包是固定revision的可移植快照。自动恢复点、显式保存、归档、成片导出与同步使用不同命令和回执，不用一个saved布尔量混称完成。 |
| 能力与验收 | ModelCatalog/Profile与许可分别锁版；以命令前后态、区间公式、保存恢复、权限和真实用户闭环验收，不按模块/DTO/Review条数宣称完成。历史审查不作为现行规范。 |

P1是可商业验证的最小完整Studio，不是只做贴纸或已有素材拼接：图片多图层编辑、创意/剧本/分镜、用途化云视频生成、真实多轨NLE、字幕/原音/配乐、项目保存恢复、独立本地会话、多Agent多模型、可撤销交付。二期增加高阶变速、反向/光流、复杂合成/3D训练、实时多人协作；不能因为分期而破坏首版字段兼容。
