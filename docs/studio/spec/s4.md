## 4 · 速度、handles、音画同步、代理与色彩

| 能力 | 具体实现与不可混淆边界 | 测试断言 |
| --- | --- | --- |
| 速度映射P1 | 线性r时s(t)=s0+r(t-T0)，D=S/r。piecewise线性TimeMap首版数据可表达，但UI先开放常速0.25..4x；二期开放曲线点编辑。对(u0,v0)..(u1,v1)，f(u)=v0+(u-u0)(v1-v0)/(u1-u0)。求反映射按v二分段，字幕源锚点用f逆。 | knots(0,0),(2,1),(4,5)：局部3秒→源偏移3秒，总4秒取5秒源；split在3秒必须在两段插入同一映射点。 |
| 平滑/反向/冻结P2 | 平滑曲线使用单调Hermite时间映射而非任意速度积分；端点斜率用单调限幅，CPU导出与GPU查同一Q采样LUT，误差门槛≤1/4输出帧。反向单独direction=-1、源倒序缓存；freeze是hold段与静音策略。未有实现时禁止转换成正速冒充。 | 单调性/端点/边界求逆测试；反向越GOP不能按负seek逐帧卡死；高阶能力缺失时项目只读或烘焙。 |
| 转场handles | cut=b，窗口[b-p,b+q)。A需在原out后q×rA（线性rate时）的额外源，B需在原in前p对应源；准确需求通过timeMap边界延拓斜率计算，P1非线性转场组合先拒绝。x=(t-(b-p))/(p+q)，视频(1-x)A+xB在线性光合成，音频gainA=cos(πx/2)、gainB=sin(πx/2)。 | A/B at150,p=q=6→A可到186，B可早到54；C源in=0处头handle不足默认拒绝。freeze必须用户确认并写入Transition policy。 |
| 音频DSP与时钟 | 解码为Float32 planar 48k，输入布局显式矩阵downmix；clip gain→pan→track bus→submix→master limiter(-1dBTP目标，需测量器验证)。源音频非1x首版明确“变速并变调”或静音，不能称保音调；二期评估独立许可的time-stretch。预览以已消费音频sample计时，非UI时钟。 | 15秒=720000sample；AAC每帧1024sample时，忽略encoder priming的纯取整尾差为896；实际initial_padding/skip_samples/discard_padding必须从所选encoder与packet metadata取得，不能硬编码896为所有设备的尾裁切。容器edit-list/metadata消除延迟，不能为凑AAC多加视频帧。 |
| 音画同步 | stream startPTS和容器edit list先解释到资产共同时间原点，不把每路首PTS各自归零。手动sync可用波形相关性提议offset，由用户确认；录音drift需显式重采样修正，记录映射而不覆盖原音。 | 非零PTS、负DTS/B帧、44.1k转48k、蓝牙延迟分开测；同步目标≤1输出帧，端部≤50ms为设计门槛非实测。 |
| VFR与代理 | import probe按真实PTS索引，VFR保留原件；生成sequence帧率CFR代理/归一中间件，保存proxy frame→source PTS映射。最终渲染按同一选择规则取原source帧，不能按proxy帧号直接seek原件。归一时保留音频实际时长，不按nominal fps拉伸。 | VFR 0/33/100/133ms映射到30fps输出0/33.33/66.67/100ms；显示取覆盖时间的源帧，规则一致且最后一帧不越源。 |
| 丢失媒体/重链接 | 外链locator在本机安全存储，项目中只ID；移动端书签/权限过期显示missing。Relink{assetId,newFileToken,expectedFingerprint}校验hash；不同hash只允许显式新版本并检查时长/流/色彩差异，不按文件名自动替换。 | 代理存在时可编辑但最终导出默认拒绝缺原件；用户明确“以代理交付”才生成标记降质的导出记录。 |
| 颜色/HDR/alpha | P1序列统一SDR Rec.709，内部linear Rec.709 FP16、premultiplied alpha；视频YUV按matrix/range显式转RGB，图像ICC先变换，旋转只应用一次。HLG/PQ/BT.2020输入保留metadata，用户确认tone-map为SDR并缓存固定版本LUT，缺metadata先要求指定解释。P1不承诺HDR交付。 | 相同RenderRecipe用于preview/final；PQ测试卡不能灰洗；透明边缘无黑边；导出MP4/H264无alpha，先在项目background上合成。HDR/ProRes/alpha MOV另列P2 preset且逐端验证。 |
| 预览与导出一致 | RenderGraph固定effect顺序：decode/color→source crop/mask→transform→clip effects→track composite→caption/text→sequence output transform。proxy仅替换采样源不替换effect语义。预览可降尺寸/丢显示帧但不换颜色公式。 | 同revision/同time/同source做离屏golden；硬件编码有损不要求文件bit一致，比较编码前帧和音频sample，记录像素容差/字体hash。 |

| EffectRegistry@1参数合同 | 编码规则/渲染断言 |
| --- | --- |
| transform2d | translateX/Y以画布像素，默认0；scaleX/Y>0且≤100，默认1；rotationDeg默认0，anchorX/Y为源归一坐标[0,1]默认0.5；矩阵M=T(position)·T(anchorPx)·R·S·T(-anchorPx)，不混用左乘/右乘。像素中心x+0.5采样；超边界transparent，P1双线性。 |
| crop / mask / opacity | crop用源归一坐标left/top/right/bottom，0≤left<right≤1，0≤top<bottom≤1；mask为灰度线性coverage，尺寸/变换固定绑定原图坐标；opacity∈[0,1]。先crop/mask再transform，alpha和RGB同乘coverage，避免黑边。 |
| colorBasic | exposureStops∈[-8,8]，线性RGB乘2^EV；saturation∈[0,2]，luma=0.2126R+0.7152G+0.0722B，RGB=L+s(RGB-L)；contrast∈[0,2]，围绕linear0.18做(RGB-0.18)c+0.18；固定顺序exposure→contrast→saturation。输出色域裁切只在最终SDR转换，不在每个节点早裁。 |
| gain / pan / mix | gainDb∈[-96,12]映射10^(dB/20)；mono等功率pan p∈[-1,1]，L=cos((p+1)π/4)，R=sin((p+1)π/4)。stereo首版使用balance，不假装mono同公式。声道混合矩阵、limiter算法版本固定在recipe，峰值保护不替代响度测量。 |
| textStyle / caption | fontRef/hash、fontSizePx∈[6,1024]、fillRGBA、strokePx∈[0,32]、shadow、lineHeight、letterSpacing、alignment、layoutRect为画布像素。文本整形先生成glyph runs，缺字走已许可fallback并报告；字幕避开safeArea。不能让各平台系统字体默认选择导致断行不同。 |
| 静态图/图片文档Clip | source.kind=imageDocument或image Asset时streamId=null，sourceRange为合成的[0,Clip.duration)静态采样域，线性1x；不得用视频availableRange规则拒绝静态图。Ken Burns是transform关键帧，不是视频生成。 |
| RenderNode封闭联合 | SourceNode(assetVersion/streamId/sourceAt/decoderLease)；ImageNode(documentVersion)；ColorNode(policyVersion/LUTHash)；EffectNode(effectId/pluginVersion)；CompositeNode(orderedInputIds/blendMode)；TextNode(cueId/glyphRunHash)；AudioMixNode(busId/routingMatrixHash)；OutputNode(presetId)。节点输出extent、pixelFormat、color、alphaMode必填，图无环；节点指纹参与cacheKey，不能只按源文件名缓存。 |

图片与视频不再是两套互不相干的效果：ImageDocument经相同颜色、字体、mask和EffectRegistry成为RenderGraph节点；可用作静态Clip、I2V首帧或产品叠加层。画布文字、字幕和品牌Logo保持确定性图层；生成模型输出只有栅格/视频候选，不能凭prompt把一段已有MP4内部物体变为真实独立可编辑图层。
