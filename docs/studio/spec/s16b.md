每项任务还按TaskInstanceId=任务ID@AppProfile版本@设备/runtime/model组合@子能力分别记结果；Apple端口的iOS/iPadOS/macOS实例不能互相冒领，第二Provider也不能借第一个的结果。单卡过大可显式增加关联子卡后再领做，现有估计只覆盖卡内首个明确Profile。任务契约：V完成=可复跑spike、环境/设备版本、真实负载、原始测量、阈值比较与go/no-go/降级决定；“no-go且证据完整”可完成验证任务，但绝不使对应实现或能力变done。I完成=实际代码/测试/文档及任务内范围均可验收，真实能力若条件未过则仍是待资格实现，不算支持；纯逻辑Schema测试可以独立验收，但不能替代模型质量/端侧性能/持久化真机结论。超过单卡范围应显式拆子任务并保父ID关联，不能通过交空stub结束。

所有任务可接未来统一runner入口，命令目前未实现；V任务各自交付独立run_probe.py，可不等待I-001，统一runner只负责后续委派。I-001须让它实际调Dart tests/C++ CTest/集成测试/模型测量器等具体适配器，未知ID、缺环境、未执行真实负载必须非零退出或返回unvalidated，不可只检查字符串存在就pass。每任务report包括specBaselineHash、选定Profile的OS/build/芯片/RAM/VRAM/driver/runtime/model hash/精度、输入尺寸/时长/fps/ctx、采样次数/温度供电、p50/p95/峰值、逐断言与人工质量表；无权重hash/设备数据显式null而非伪造。数据主张始终区分official/design/tested。

许可与授权：个人商业用途不变；商业模型/组件缺许可的项目执行默认allow_with_warning，保实际license事实与审计；这不是授予预算/云上传/系统权限/肖像声线同意，不绕真实provider鉴权/拒绝、签名完整性、资源不足或不支持模式。task/planned也不授权本轮安装SDK、下载权重、打开私有工程、部署或生成。未来收费实验/账号/购买设备/对外发送/发布均需对应明确授权。
