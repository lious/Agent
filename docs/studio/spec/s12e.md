建议首批100条未硬编码指令，含单/多步、指代不明、否定/纠错、模型未装、越权、循环、删除后压缩和取消；留holdout不参与prompt调优。分开报JSON有效率、参数合法率、目标/工具正确率、端到端完成率、人工改动、危险越权执行及Undo正确性；旧建议≥90%完成且危险执行0是待批准测试门槛，不是成绩。权利图片30—50张和视频短长/VFR/噪声/多语/无声难例是样本计划，未收集；报告全部失败/unknown/blocked分母，冷/热load、prefill、首token、decode、p50/p95、热/电与峰值同时记录，不能拿平均值掩盖严重失败。
