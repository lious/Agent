## 10C · 动态PlanGraph：受约束扩图、预算与调度

| 机制 | 算法/状态/失败约束 |
| --- | --- |
| 自然语言→类型图 | Director生成结构化PlanDraft，只能引用NodeRegistry中handlerPin和inputSchema；PlanCompiler先验Schema，再验ID唯一/引用/同ns/无环/资源能力/阶段审批/写集。LLM输出解释只保DecisionNote(reasonCode,evidenceRefs,alternativesCount)，不保存或索要私密推理链。缺模型原生tool能力时用显式JSON计划通道，仍走同一校验器。 |
| 节点与条件 | model/tool/qa/expand/reduce/proposal/human/checkpoint；条件仅always或上游QAFinding.status==pass\|fail\|unknown，不执行表达式脚本。guard.source必须是依赖祖先且是qa节点；guard=false→skipped，后续allSuccess不把它当成功。allTerminal仅允许声明接受失败/缺输入列表的reduce；否则DEPENDENCY_FAILED。 |
| 扩图/fanout/fanin | expand必须先冻结输入条目有序hash列表，再以(parentPlan,node,itemHash)稳定派生ID；新图version+1，parentPlan指原pin。先验总节点/深度/预算，再CAS activePlanVersion；不得回写已提交节点的prompt或撤销已付费事实。批次/style variations map成独立子节点，reduce按固定item顺序聚合结果/缺失项，不按网络返回顺序。 |
| replan/版本保留 | 只替换受影响未完成子图；已正确候选可按相同输入/输出hash、当前授权/删除屏障显式retained引用，不重生成。旧图仅供追溯；旧lease结果不能发布到新图。原Call仍要按原账单结算；适用新图的旧产物需经依赖/授权重验后以retained引用显式接纳，不伪造新一次生成。新审批绑定新pin，不能把审批ID复制到改过prompt的节点。对外部已受理Job只继续对账，展示其是否仍适用。 |
| 预算聚合 | 预算真相沿用BudgetLedger/Reservation；Limits只是请求上限。父子额度取min(用户上限,父剩余,单模型上限)，子预约计入父待结算，不能靠spawn/reset绕过。累计token包含失败/repair/critic；未知付费提交继续占额度；费用整数microunit+currency，换汇需显式报价，禁止浮点相加。 |
| 默认防爆策略 | 单图≤64节点、fanout≤8、replan≤3、QA修复≤2轮；每个模型Run默认≤4次Iteration/工具往返，仍受父图总token/费用/wall预算。所有数值是可配置设计护栏，不是实测最佳值。全图model iteration硬上限≤64，反复新建子Run不重置。等待人工/远程的超时分开记录，用户可延长，不自动增加费用额度。 |
| ready/claim | 依赖满足+guard成立+当前权限+预算预约+资源lease才ready；同workspace本地SQLite BEGIN IMMEDIATE原子领Step，lease含executorFence/owner/bootEpoch。Run lease负责协调，Step lease负责执行，互不替代。GPU/高内存模型默认物理重槽1；预览/音频实时优先，重模型加载与推理不与编码器无限抢资源。 |
| 取消/重试 | 纯分析/只读网络暂错最多重试2次（总attempt≤3），指数退避带抖动且受剩余deadline；license/权限/Schema/不支持能力不重试。付费提交timeout→submit_unknown，按10D查账，绝不按普通retry重新POST。GPU不可抢占时标cancelRequested并禁发布，等执行器回收释放模型/纹理/缓冲。 |
| 断点续传 | 本地纯计算按8Q/端侧checkpoint恢复；mobile挂起前持久化，不保证后台持续推理。重新启动更换bootEpoch，旧单调时钟lease全失效，验证checkpoint输入/模型/运行时hash才复用。云长Job由可选后端worker持有；App不在线也不能假定本地dispatcher在运行。 |
| 写入与补偿 | Agent只能提交Proposal→CommandBus白名单命令→项目单写者readSet/CAS/field locks。并行Agent生成候选可并发，不能并发写同一工程。删除临时文件/退款/覆盖不作为自动compensation；已提交副作用只登记补偿建议，需原权限和必要确认。内部临时lease/预约可幂等释放，已实际计费不“撤销为零”。 |

// dart/packages/harness_plan/plan_compiler.dart + scheduler.dart
compile(draft, registry, capabilitySnapshot):
  validateDraftSchema(draft)
  graph = resolveAllPinsAndInputSchemas(draft)
  assertUniqueIdsAndNamespacedRefs(graph)
  assertDAG(graph) // DFS visiting/visited O(V+E)，不靠执行时超时判断环
  assertGuardAncestorsAndReducerFailureContract(graph)
  assertTotalLimitsAndNoCapabilityEscalation(graph)
  return immutableCanonicalGraph(graph)
expand(oldPin, itemRefs, draft, expectedRecordVersion):
  freezeSortedUniqueItems(itemRefs); requireWithinParentReservation()
  next = compile(spliceOnlyPermittedPendingSubgraph(oldPin,draft), registry,caps)
  transaction:
    assertActivePlanAndRecordVersion(oldPin,expectedRecordVersion)
    persistGraphAndDerivedSteps(next)
    retainOnlyDependencyIdenticalAuthorizedOutputs()
    append(plan.replaced); CAS activePlanVersion=next.version
// 所有起始状态/复用/失效都有事件；没有“模型自己判断能写数据库”。
claimReady():
  BEGIN IMMEDIATE
  candidate = readyByPriorityAndFairness()
  if none and no pendingExternalOrHuman and nonterminalStepsRemain:
      mark needsReview(DEPENDENCY_DEAD_END)
  reserveParentAndChildBudget(candidate); claimResourceLease(candidate)
  UPDATE h_steps SET state='leased', executor_fence=executor_fence+1,
    attempt=attempt+1 WHERE ... AND state IN ('ready','retryWait')
  COMMIT // 预算与Step领用同workspace事务；外部provider提交在commit后由outbox执行
