## 1 · 产品骨架、跨端复用与方案选型

产品有四个协作工作区：Brief/剧本 → 故事板/素材候选 → 图片画布/多轨时间线 → 导出/工程归档；会话侧栏贯穿四区。用户既可从自然语言开始，也可完全手动剪辑。Agent只能建议和生产候选，不能取得用户编辑器的隐式最高权限。

| 路线 | 真实优势/适用层 | 本项目决定与限制 |
| --- | --- | --- |
| FFmpeg＋共享编辑内核＋各端硬件适配（用户已定主架构） | Flutter/Dart负责UI、可编辑文档和独立本地Harness；C++20以libavformat/libavcodec/libavutil/libswresample/libswscale为共享媒体底座，libavfilter按需与许可启用，各端适配硬件帧/纹理/音频。 | FFmpeg不再仅是桌面扩展，移动普通MP4也走共享容器/时间戳路径。Dart不是实时像素处理器；FFmpeg不是完整NLE或会话引擎。Web另实现MediaPort，不能把移动FFmpeg二进制或FFI直接搬过去。当前是选型落定，尚非构建验证。 |
| React/TypeScript+Electron/Tauri+RN | Web与桌面复杂编辑器生态好、贴近第三岗位；TS SDK适合外部插件。 | RN移动与Web DOM时间线不等于同一UI；Rust/TS/Swift/Kotlin桥接仍需重媒体实现。本项目无现成TS产品可迁移，改栈不自动解决codec，故不为招聘关键词重复造两套Harness。保留JSON/C ABI便于未来TS壳。 |
| IMG.LY CE.SDK（商业采购候选，不默认已购买） | 官方覆盖native iOS/Android、Flutter移动、Web、Electron、macOS相关形态；带图像视频编辑/渲染/场景归档，能减少底层工作。 | 官方支持页称没有独立Windows原生SDK，Windows走Electron/Web；移动浏览器不支持其视频编辑/导出，Firefox视频导出受限。必须实测自定义patch映射、roll/slip/slide、nest/变速/精确色彩、离线许可证、多App授权与可移出项目。价格/条款待询，不编报价。 |
| VE.SDK / 其他移动商业编辑SDK | 适合快速集成iOS/Android视频编辑；VE.SDK与CE.SDK不是同一个平台表。 | 不能把移动产品支持偷换为Windows/Web全覆盖。只有厂商书面确认平台/多App/OEM、版权责任、导出限制及全部关键fixture通过，才替换MediaEnginePort；不能宣称自动支持本设计所有NLE操作。 |
| MLT / Shotcut / Kdenlive路线 | MLT有producer/filter/transition/consumer和playlist，适合成熟桌面NLE；可研究边界与恢复思路。 | 读过MLT playlist.c及Shotcut timelinecommands.cpp。MLT核心LGPL-2.1+，模块另审；Shotcut GPL-3.0+，不复制其命令代码到闭源App。MLT不是已证实iOS/Android/Web统一SDK，旧框架文档的8bit描述也不能代表全部现状。 |
| GStreamer/GES | 有pipeline、时钟、插件、GES时间线，适合桌面/嵌入式/后台媒体。 | 核心LGPL但插件与codec许可逐一审，移动包/硬件纹理/Web集成需验证；并非导入即获得本产品UI/项目/AI边界。P1不同时维护第二条完整pipeline。 |
| OpenTimelineIO | Apache-2.0；交换clip/track/gap/transition/nest/time信息，可导入导出。 | 不是解码器、编辑器UI或完整渲染引擎；不定义所有效果/字体/AI溯源。Studio包为主格式，OTIO导出附损失报告，自定义效果保metadata且可选烘焙，不承诺往返无损。 |

```text
apps/studio/                         # 品牌App composition root；无领域业务复制
packages/studio_contracts/            # JSON schema、Q/Id/Error、能力名；纯Dart
packages/studio_document/             # Sequence、EditAlgebra、PatchValidator、OTIO映射
packages/studio_harness/              # Session/Context/Agent/Run/Policy/Budget；不依赖UI
packages/studio_generation/           # Brief、PromptCompiler、Candidate、Provider协议
packages/studio_store/                # SQLite、CAS、journal、snapshot、recovery
packages/studio_editor_ui/            # timeline/board/image/session widgets
packages/studio_sdk/                  # 对其他App的稳定入口；仅此处组装依赖
native/studio_media/{include,src}/    # C++20 GraphCompiler、scheduler/DSP/RenderGraph
native/studio_media/ffmpeg/           # AVIO/demux/codec/resample/scale/mux；不读会话DB
native/platform/{apple,android,win,linux}/ # 硬件帧/纹理/audio/file，不重写NLE
web/studio_media_web/                 # JS WebCodecs+Worker+WebGL2受限适配
native/studio_models/                 # llama.cpp/Whisper包装；与media资源仲裁
services/generation_gateway/          # 云凭据/上传授权/付费job/对账；非本地会话存储
schemas/{project,command,event,brief,prompt,provider}.schema.json
fixtures/{nle,project-recovery,provider,session,render}/
docs/{adr,contracts,algorithms,runbooks,licenses,release}/
```

依赖只能从UI/SDK→用例→领域与Ports；store/media/model/provider是Ports实现，领域不import插件。核心SDK输入AppProfile（appId、tenantPolicy、features、brandAssets、modelCatalogId、exportPresets、region），不能读取其他App沙箱。跨App复用的是包和契约，不是偷偷共享聊天、凭据或照片；用户显式导入Studio工程时重映射namespace和授权。Web采用独立origin强隔离；同origin的两个品牌只做逻辑隔离不称安全边界。

| 阶段 | 必须可用 | 不承诺 |
| --- | --- | --- |
| P1原生端 | 共同领域合同；优先完成一端竖切后用同fixture移植iOS/Android/macOS/Windows。至少经过每端自身codec/纹理/字体/恢复门禁才标支持。 | 不把同时存在4个插件目录等同4端已通过；不承诺所有设备4K实时。 |
| P1 Web | 项目/会话/生成/图片；桌面浏览器只有能力探测+fixture通过才开放视频编辑与导出。 | 无FFI、文件系统/后台/codec不同；移动Web不列全功能视频承诺。 |
| P2 | 高级NLE、授权商业SDK可替换实现、多人协作/高级3D、可选服务端渲染。 | 云端渲染需另一次上传批准，不是本地失败时自动上传。 |
