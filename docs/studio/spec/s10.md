## 10 · 模型可换，Harness和上下文必须独立

| Agent/模型Profile（首版配置） | 职责/权限 | 路由与降级 |
| --- | --- | --- |
| DirectorAgent → deepseek-v4-pro（云文本） | 把用途Brief变成Script/Scene/ShotSpec；只能read project摘要、propose script/shot、delegate。 | 不读图像假装有视觉；官方本轮模型页列该model无vision。拒绝上传可选择本地Qwen提议较简方案，先展示能力降低并重新编译上下文。 |
| VisualAgent → deepseek-flash（云视觉） | 基于用户批准上传的缩略图/参考图做镜头外观建议、质量筛选，不能自行上传完整相册。 | 官方vision页核验图片输入；每次只取scope内引用。抽帧是图片上传，不等同完整video理解；批量/分辨率在profile限制。 |
| EditAgent → Qwen3-1.7B GGUF Q4_K_M（端侧目标包） | 理解剪辑意图，产生白名单EditCommand建议；不负责视频扩散生成。llama.cpp推理，JSON grammar+语义校验。 | 权重卡Apache-2.0、llama.cpp MIT分别登记。自建量化包要固定原权重commit/转换工具/量化hash/模板/tokenizer；当前未构建未测速，不承诺任何iPhone能稳定跑。默认context起始4096、输出1024作为待测配置。 |
| SubtitleAgent → Whisper base 本地目标配置 | 解码16k mono片段→ASR segment→source/timeMap映射→Caption proposal，手改text不被重识别覆盖。 | 分块30s+重叠1s需去重；静音/音乐幻觉过滤和language配置测试。Whisper引擎/权重许可各入SBOM，不能把ASR当LLM或说全语言效果相同。 |
| GenerationWorker → wan2.6视频profile | 按已批准PromptDraft提交云视频并登记Candidate；不是具有无限工具权限的聊天Agent。 | 不将本地模型卸载/内存不足自动解释成允许云上传。图片生成可沿用经核验的独立image profile，不能拿视频API接图像模型。 |

ModelProfile字段：id/version/provider/remoteModelId/resolvedModelVersion可空/localPackageHash/tokenizerHash/chatTemplateHash/modalities/contextLimit/toolDialect/jsonSchemaMode/parameterAllowlist/region/dataPolicy/costTableVersion/capabilitySnapshotHash。Provider Port只接CanonicalContext，不拥有Session数据库；切模型后重渲染system/tool格式和token计数，不搬KV或供应商专有reasoning块。两Agent可分别跑不同模型，即使都在线也不共享隐式上下文。

```text
ModelProvider.generate(ModelRequest, CancelToken) -> Stream<ModelEvent>
ModelRequest {id,runId,profileId,contextSnapshotId,messages[],toolSchemas[],
 maxOutputTokens,sampling,inputHash,privacyApprovalId?,budgetReservationId}
ModelEvent = TextDelta | ToolArgumentDelta | ToolReady | Usage | Finished | Failed
// 半截JSON不是ToolReady；parse/schema/semantic/policy验证全过才进工具审批。
ContextCompiler.compile(branchHead,agentId,modelProfile,scope)->ContextSnapshot
ContextSnapshot {id,modelProfileId,tokenizerHash,inputHash,parts[],tokenCount,
 estimated:bool,sourceEventRange,summaryRefs[],redactionVersion,createdAt}
ContextPart {kind:system|constraint|brief|selection|memory|summary|recent|toolResult,
 contentRef,sourceRefs[],priority,tokenCount,trust:trusted|untrusted,revocationVersion}
DurableScheduler.tick(nowMonotonic,deviceEpoch)->RunLease[]
ToolRuntime.execute(validatedCall,approval,lease)->ToolReceipt
// 租约fencingEpoch用于拒绝旧worker回写；device重启所有本地旧lease失效。
// 没有用户审批的外部副作用不进入工具执行；回放事件不调用Provider。
```

| 机制 | 具体算法与边界 |
| --- | --- |
| 上下文装配/压缩 | 预算B=contextLimit-reservedOutput-safetyMargin；固定约束与当前有效意图→当前工程scope/锁定字段→当前工件→带证据检索→过滤后的近期交接。0.8B触发有界压缩。第10A节Snapshot(watermark)+tail、意图reducer、privacyEpoch与原子发布为唯一规则；旧版“原事件正文永远保留”作废：可保留无正文事件头，删除必须传播至摘要/检索/缓存/派生副本。摘要不能覆盖当前意图，也不能靠保留用户否定原文才能防复活。 |
| 记忆/RAG | 首版项目级FTS+标签+资产/镜头/决策索引；embedding可选独立profile，不强制下载。MemoryItem{sourceRef,sourceVersion,aclVersion,quoteLocator,confidence,revoked}必须可追溯。企业邮件/IM connector只作后续授权插件，不默认扫描用户账号。来源/附件/OCR是untrusted data，不得当系统指令。 |
| 多Agent编排 | DAG Director→Visual审图→逐镜GenerationWorker→EditAgent提出组装→SubtitleAgent；子Run独立model/context/tools/budget，父预算预留上限之和不可超父额。交接传ArtifactRef+结构化摘要，不共享可写内存。依赖失败只阻其下游，可保留其他镜头成果。 |
| 并发与写入 | 逻辑可并行：云Visual与本地Edit可同跑；物理本地heavy默认一个，export/preview优先。所有正式编辑单写者CAS；两个Agent同rev提案可并存，先接受者提交，后者必须rebase。不能把不同branch当安全双写同一工程。 |
| 持久执行/恢复 | Run/Step/ToolCall/outbox/receipt落SQLite，lease使用单调时钟与bootEpoch，远端用服务端租约；重启先回放投影→回收旧lease→查远端job状态→恢复未完成纯计算步骤。工具intent/receipt状态分离，付费提交unknown不重复执行。 |
| 预算/Trace | BudgetLedger按currency和计量单位分账，reserve/settle/release唯一receipt；父子预留硬约束，本地token/时间上限也可配置。Trace关联session/branch/run/tool/model/inputHash/revision/job/quote/usage；日志存脱敏元数据，prompt/图像正文需用户开启诊断才导出。 |
| Skill与扩展工具 | SkillPackage{manifestHash,version,requiredTools,inputSchema,outputSchema,testFixtures}签名或用户确认安装；只声明任务步骤不增加权限。MCP未来adapter只挂受审工具目录，移动端不执行任意本地shell；toolUse/结构化输出不是安全边界。 |
| 模型管理 | 下载到staging、断点续传、签名manifest+sha256验证→installed；load/ready/drain/unload独立状态，busy时不能卸载指针。磁盘不足/校验失败隔离包，旧版本保留；内存预算含权重+KV+临时buffer+媒体面板，不以文件大小当峰值RAM。 |

纯离线Profile：所有HTTP provider禁用，可本地规划/剪辑/字幕/图片基础编辑/导出；若模型未安装则手动编辑仍可，不能把预设脚本伪装成真实LLM。离线不支持云视频生成必须明确显示，不假装能用1.7B文本模型生成视频。商业版本通过服务器支持付费生成/账号同步，但Session与Context仍在本地由同一Harness拥有。
