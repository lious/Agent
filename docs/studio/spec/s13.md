仍需继续设计而非仅“等待真测”的范围明确保留：Web demux/mux最终库及锁版/许可审计，HDR→SDR固定LUT与limiter DSP的具体算法版本/系数，以及P2高阶曲线/反向、复杂3D、多人实时协作详细协议。当前已定义完整项目合同和命令/归档/会话边界，不把这些更大范围说成已全部设计完。当前首版可编码主线不要求P2生效；未知能力按本节门禁只读/禁用，不能用占位输出冒充。另有必须构建/真机/服务/合同才能验证的G-MEDIA/G-MODEL/G-VIDEO/G-COMMERCIAL，不可能靠文档断言放行。

下一步实施应先做“可保存项目＋纯函数NLE＋会话diff”竖切，再接一条真实codec与一个视频provider，随后逐端扩展；不是先生成数百个空类。本页已经把关键决定落下，但仍不声称解决未写/未测的全部底层工程。发现设备或合同不满足门禁时更新ADR和capability，不推翻本地会话/项目格式的独立性。
