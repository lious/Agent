## 10F · 影视质检：证据定位、unknown与最小修复

| 维度 | 确定性/模型/人工分工 | 定位与修复边界 |
| --- | --- | --- |
| 语义/指令/商品 | 确定性验证已确认claims/价格来源、文字叠层与脚本字段；VL核对可见主体/动作/SKU形状，模型分数需校准；功能真实性/商业宣称最终人工确认。 | 定位shot/region/FactRef；错误商品镜头替换候选，不自动改商品事实。不能仅靠OCR/字幕判画面正确。 |
| 故事/叙事/情绪 | 脚本节拍/角色出场/镜头覆盖/时长预算可规则检查；因果、悬念、表演情绪由模型辅助+人工审片，无法观测→unknown。 | 依赖ScriptBeat/Shot；修复最小镜头覆盖或顺序提案，不让评分器重写整部片。 |
| 人物/连续性 | 角色pin/rights/服装override可确定校验；跨镜身份、视线/180度/光色衔接由VL观察及人工。相似度不是肖像授权，也不保证身份像素锁。 | 定位角色版本、前后镜帧与ContinuityFinding；保留已正确镜头，角色全局升级需显式diff。 |
| 运动/摄影 | 编码损坏/PTS逆序/实际帧数/冻结重复可规则测；动作合理、穿模、相机意图需连续帧/视频能力模型或人工，抽帧漏动作则unknown。 | 证据源PTS/帧区间+模型能力；无真实视频理解不伪造运动评分。重做该镜而非把滤镜当动作修复。 |
| 音画/对白/字幕 | probe采样率/声道/时长、cue重叠/越界/缺字可确定测；响度/true-peak依交付preset，AV延迟/可懂度需分析+人工；词时间戳不等于说话人识别。 | 定位sampleRange/cueId/关联clip；对齐或ducking命令只改未锁字段，手改字幕文字不覆盖。口型同步是独立能力，未接入时unknown。 |
| 画质/剪辑/转场 | 输出codec/pixel格式/分辨率/色彩标签/handles可确定检查；闪烁、身份漂移、蒙太奇意图需时序分析/人工。黑帧/闪白先查用户是否有意设计，不一律判错。 | 定位Transition/Effect/片段边界；未注册特效仍UNSUPPORTED_EDIT_TECHNIQUE，不让LLM伪造渲染节点。 |
| 版权/安全/隐私 | 用户素材/肖像/声音授权及到期、云上传同意、已删依赖为确定性hard gate；模型/组件商业许可事实单列warning按1C默认放行；内容安全模型只做辅助，未成年人/真人高风险走显式授权和必要人工。 | 无授权阻断新生成/发布；删除传播到缓存，不假装能撤回已经导出的外部文件。 |

```text
QAEvaluator.evaluate(subjectPin, QAProfilePin, evidenceBudget) -> QAFinding[]
// QAFinding字段完整定义在10I。status=pass|fail|unknown；mode=deterministic|model|human。
// score与confidence可null；没有calibrationHash的模型分数不能自动当“95%可靠”。
RepairPlanner.propose(findings, dependencyIndex, lockedFields, remainingBudget) -> RepairPlan
  assertEachFailureHasSourceBoundEvidence()
  target = minimalProducerNodes(findings.affectedScopeHash)
  closure = descendantsWhoseInputHashesActuallyDependOn(target)
  addAffectedBoundaryNodes(transitionHandles,audioCrossfade,captionTiming)
  preserve = acceptedOutputs - closure
  if closure intersects manualLockedWriteSet: return NeedsReview(diff)
  draft = newVersionReplacingOnly(closure); retain(preserve)
  return proposal(draft, costQuote, approvalRequiredForChangedPaidPrompt)
// 确定性硬门：例15s/30fps=450帧；实际导出不得偷偷少帧。
// 模型阈值由具体QAProfile+离线标注集校准，不给所有模型套0.8通用阈值。
// unknown不等于pass；硬性发布项unknown→人工确认/阻断；软项可带警告人工接受。
// 默认最多2轮修复；轮次、critic、重试都计入同父预算。
// 只有已获批的精确prompt/资源/报价可付费执行；“自动修复预算”不是空白支票。
// 可自动做无费用、未锁范围内的确定性提案/预览；改变内容需用户接受Command。
// 已通过镜头不重新生成；变更字幕只重算cue/音轨依赖，不失效无关视频候选。
```

模型SLA不是一句“高质量”：EvalRun按profile版本、数据集pin、用途/画幅/时长分桶统计接受率、人工修改成本、unknown率、成本/通过镜头、排队/首结果/完整成片p50/p95与失败/超时/未知账单比例；失败和未完成样本不能从分母悄悄剔除。任何目标值是产品验收目标，未做真实模型/生产负载测试前不写达成率。质检与生成最好用独立Profile/人工盲评减少同模型自证偏差，但仍不能消除偏差。
