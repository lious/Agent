## 12B · 权限、素材取回、录音与离线边界

```text
PermissionBroker.request(scope:pick|savePhoto|recordMic|readExternal|modelDownload|cloudUpload,
 userGestureId,resourceRefs,purpose)->Grant|Denied|Cancelled
ImportHandle {id,namespace,selectionToken,state:selected|fetching|localReady|failed|cancelled,
 sourceKind:localFile|photoProvider|documentProvider,bytesExpected:U64|null,
 bytesReceived:U64,localBlobHash:Hash|null,grantId:Id,error:Id|null}
MediaImportCoordinator.materialize(handle,cancel)->LocalAssetReady
AudioCapturePort.start(micGrant,deviceConfig,tempFileToken)->CaptureSession
AudioCapturePort.stop(session)->ValidatedAudioCandidate
// Apple Photos/Android Photo Picker/桌面文件选择按用户选件，不先索要全相册。
// 系统选择器可能从iCloud/云相册取原件；localReady前不称严格离线可用。
// 用户可看阶段/取回bytes、取消；临时选件权限可能失效，不保证opaque URI永久可读。
// 保存相册独立按需授权；导出到本机FileToken不强制申请相册写权限。
// 录音拒绝/电话/路由变化/后台中断安全stop，未完成文件先验证或隔离，原音不动。
// 采样率/声道取实际设备，记录origin/latency，经swresample变工程48k；不假定硬件恰48k。
// 降噪/克隆不能在用户不知情时打开麦克风；CaptureState与Job/Project revision分离。

```

离线开关禁止业务云推理/上传；模型下载、商店验证和系统素材取回分别披露，不宣传整个OS零联网。严格离线验收须先取得本地素材/已装权重，再断网跑真实任务；缺权重保留手工编辑但标Agent不可用。RAW/Live Photo/动图/不支持ICC等须明确转换成新资产或拒绝，不能把首帧当完整动态内容。系统授权/云取回不意味着用户同意把素材交给AI provider。跨端Grant只保本机安全store，工程包不带系统书签/URI密钥。
