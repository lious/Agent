## 8K · 素材一键成片、I2V、首尾帧与续写：不同路径

| 素材一键成片 mediaMontage | 不是付费生成的默认编辑流程 |
| --- | --- |
| 入口/槽 | 相册/活动/商品素材持有者；必填图片/视频1..200、purpose、目标时长/比例、按拍摄时间或手动顺序；可选音乐1、旁白1、标题/品牌/节奏。数值是产品首版交互上限，不是FFmpeg能力极限。云分析默认关闭，端侧不足时让用户选上传或仅做基础分析。 |
| 预检/分析 | probe可解码性/VFR/旋转/色彩/音轨；精确hash去重只合并相同字节引用，感知相似只建议。输出QualityFlags(黑帧/模糊/冻结/遮挡/裁剪安全区)、SceneRanges、ASR、OCR与视觉证据。字幕≠运动理解，短动作需按需深读；同语义缓存键不重复付费分析。 |
| 规划/交互 | 素材托盘可排除坏片/恢复误筛、拖顺序/设in-out/人脸安全区。EditPlanner产每镜sourceRange/timelineRange、静图变换、标题/BeatGrid切点；先最低帧，再剩余按权重最大余数分配，稳定ordinal破并列，受可用素材/handles上限制约。不足时缩短、明确重复或提议补镜；不自动拉长冻结或开付费生成。 |
| 确认/执行/交付 | 预览分镜与文字→本地白名单EditCommand batch→NLE字幕/配乐/手动微调→交付。Ken Burns/转场/裁剪是确定性编辑，不标“AI生视频”。缺镜只有用户切allowNewGeneration并批准新图节点后才付费。标记不采用素材不等于删除CAS。 |
| 错误/锁 | 坏文件隔离并报告；少素材可完成较短版本，不能黑屏凑数。保持锁定in-out/字幕/音量键；节拍对齐只提出移动切点，若越锁或超handles报冲突，不悄裁对白。引用失效按缺素材重链接合同，不虚构原画。 |

```text
【montage.edit-plan@1.0.0；LLM仅产编辑提案，不发送视频生成API】
素材清单={{evidenceIndexedSources}}；顺序={{ordering}}；目标={{totalFrames}}；
画幅={{aspect}}；音乐节拍={{beatGridOrNone}}；锁定={{locks}}；新生成=false。
只使用已确认的可用sourceRange；输出clip顺序、in/out、crop/pad、
标题层和切点理由。若素材不足明确短缺帧，不杜撰新镜头、不改变锁定字段。
【完整填槽示例】
素材=A桌面视频可用[0,3s)、B商品手部视频[1,6s)、C授权产品照片静态4s；
顺序=手动A/B/C；目标360帧/30fps；画幅9:16；节拍=无；
锁定=B字幕“轻装也从容”。新生成=false。
提案：A取90帧，B取150帧，C取120帧；C仅1.00→1.05确定性缓慢推近；
3段硬切，B字幕保持；remoteJobs=0，云生成报价=0，不代表设备算力/授权素材无成本。
```

| 图生视频 i2v | 独立输入合同 |
| --- | --- |
| 入口/素材 | 单图用户；必填已授权首帧1、可见动作/运动目标、purpose、时长；可选角色pin、相机意图、原图可编辑crop。多张照片不能直接塞单first_frame；要参考多图需切R2V并确认角色限制/报价。 |
| 路径与产出 | 预检清晰度/主体完整/alpha/比例与授权→ImageAnalysis证据→MotionPlan(主体动作/背景运动/机位)→确认首帧CropPlan→PromptCompiler→批准→候选运动/身份QA→NLE配字幕音乐→交付。未证实静图里发生的事不能当真实运动证据。 |
| 编辑/失败 | 首帧与运动意图分别可版本化；锁定字幕不被重生成覆盖。过大运镜/物体出框/复杂手部失败可缩小动作、换图或确定性推拉，必须标新路线。不能保证静止主体纹理逐像素不变或精确焦段/物理速度。 |

```text
【i2v.single-motion@1.0.0】
保持参考图中{{subject}}的{{identity}}，{{subjectMotion}}；
背景{{backgroundMotion}}；镜头{{cameraMotion}}；{{lightContinuity}}。
【完整填槽示例】
保持参考图中青色纸船的折痕与轮廓，纸船缓慢向画面右侧漂移；
背景水面出现轻微连续涟漪；镜头固定中景；维持柔和阴天光线，不新增人物或文字。
素材=1张自有合成纸船图；crop=9:16已确认；API=wan27-i2v/5s/720P。
无第二帧硬锚点，不声称纸船最终位置精确；必要时NLE缩短到最佳片段。

```

| 首尾帧 firstLast | 真实双锚点而非I2V改名 |
| --- | --- |
| 入口/槽 | 设计师/转变镜头；首帧1＋尾帧1有序必填、目标动作/过渡、2..15s整数与画幅。UI标“开始/结束”且可交换；必须同一裁剪计划或用户逐帧确认，图片对比不能偷偷拉伸。 |
| 预检→规划 | 两图授权/格式→比较主体身份、物体数、空间、光照与可行变化→AnchorFeasibilityReport；完全不同身份/互相矛盾状态要求明确“艺术变形”而不是自然连续动作。生成机理不保证路径/端点像素精确。 |
| 确认→QA→NLE | 用户确认锚点、变化轨迹建议与模型支持→编译真实media first_frame+last_frame→单独批准→首尾邻域/中间动作/身份QA→NLE裁剪与字幕声音→交付。firstLast不支持时阻断；提议单图模拟需用户改模式。模型不保证端点时，不能悄悄强贴静帧遮盖跳变。 |
| 失败/费用 | 中间形变/路径不成立→较小变动、加长允许时长或拆成多镜；额外锚点不是当前API能力，不能上传三帧冒充。手改终点会使该镜候选/批准失效，其余镜头不重做。 |

```text
【firstLast.bounded-change@1.0.0】
从已确认首帧出发，{{sameSubject}}通过{{singlePlausibleAction}}接近尾帧状态。
保持{{invariants}}，{{camera}}；不引入与两个锚点冲突的新主体。
【完整填槽示例】
从已确认首帧出发，同一青色纸船随轻缓水流向右漂移，接近尾帧右下方的位置。
保持船的数量、折痕和阴天光色，固定机位；不引入与两个锚点冲突的新主体。
输入=有序first_frame/last_frame各1；参数5s/720P，无driving_audio。
QA=起终邻域与中途轮廓/水流连贯；这是模型约束，不是确定性路径动画。

```

| 视频生视频：续写/重绘/运动分开 | 用户可操作合同 |
| --- | --- |
| 入口/槽 | 视频创作者选“延续此镜头”而非泛v2v；必填原视频1、尾上下文range(2..10s)、新增动作、期望新增时长；可选真实尾锚点1。另有“参考外观新拍”“参考运动迁移”“风格重绘”互不混称。 |
| 预检/分析/规划 | FFmpeg probe→用户批准规范化/裁取尾上下文→时间序列分析姿势/方向/光色/声音/未完动作→ContinuityPlan。nativeContinue请求总时长=上下文＋新增，必须整数2..15且大于上下文；非整数源时长先给明确裁剪/取整方案，不静默丢帧。 |
| 确认/生成/QA | 界面并列“保留原片”“上传上下文”“追加预计秒”“按全长计费秒”；确认路线和音轨隐私→逐轮生成→接缝/身份/曝光/运镜/对白QA→只入响应后缀。失败优先手动切点/插入镜头提案；尾帧模拟必须带approxContinuation且另批，不作为自动fallback。 |
| 可编辑/限制 | 原NLE源范围与音轨默认锁；新段独立Clip/字幕/音轨可trim。不能连续无限续写来规避上限与预算；累计漂移每轮审核。原片不包含所需运动时，单帧摘要无法恢复准确速度；未核实风格重绘Profile维持禁用。 |

```text
【continue.action-tail@1.0.0；nativeContinue逐镜模板】
接续已批准片段末尾的{{ongoingAction}}，同一{{subjectIdentity}}随后{{nextAction}}。
保持{{screenDirection}}、{{cameraContinuity}}与{{lightingContinuity}}。
不要重演整段已完成动作；台词/音乐只按明确批准的声音方案处理。
【完整填槽示例】
接续已批准片段末尾向右行走的动作，同一蓝外套短发岚随后走到站台门边自然停步。
保持向右屏幕方向、固定侧面中景与黄昏暖色侧光。
不要重演整段已完成动作；台词和音乐仅保留NLE已有独立音轨。
原片10s；上传尾2s；请求duration=8s→预计新增6s；
返回含2s前缀，验证后只取后6s，原10s不重写。provider生成原声音轨默认不采用。
若改选尾帧I2V：改route=tailFrameBridge/output=approxContinuation，另报5s费用，
prompt仍是动作建议，但不声称带入原视频速度/节奏或是原生续写。
```
