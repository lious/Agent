## 10H · 可选生产后端与完整故障时序

默认本地工程、会话、Harness、端侧模型不强依赖服务器。需要持久云生成/跨设备服务时采用一个Python API/control模块化服务（FastAPI候选，锁依赖后验收）+PostgreSQL持久状态/事务队列+S3兼容对象存储+独立CPU/GPU worker；Redis只作可丢缓存，不当状态真相，首版不引Kafka/多套消息中间件。Dart与Python共用下节wire Schema/命令语义fixture，但不是宣称100%同一语言二进制；C++媒体内核与Provider适配继续分层。LangGraph如后续引入，只能替代一层调度并通过checkpoint/幂等golden，不得与现有scheduler争领Job。

```text
// backend/api / control / worker / provider_gateway / eval；设计，不是已经部署
POST /v1/runs                 {RunStartTicket, planPin, idempotencyKey}
POST /v1/runs/{id}/controls   {ControlIntent, expectedRecordVersion}
GET  /v1/runs/{id}/events?afterSeq=... // SSE断线重放；token不放URL
POST /v1/approvals            {executionDigest, userDecision, challengeId}
POST /v1/provider-webhooks/{profile} // 验签、租户/job绑定、inbox去重
GET  /v1/artifacts/{id}/grant // ACL+rights/privacy校验，短时、指定对象下载授权
// ns由认证appId/tenantId/workspaceId映射，忽略模型传来的任意tenant。
// 关系状态PG；按tenant+id唯一幂等，row lock/SKIP LOCKED领任务+server UTC lease+fence。
// 队列至少一次投递，不声称exactly once HTTP；intent/receipt/outbox提供幂等业务效果。
// 对象key随机/namespace隔离，内容hash去重不能泄露另一租户是否有同文件。
// token/密钥在服务端密钥库或各App系统安全存储，不进工程包/会话导出。
TenantQuota {tenantId,maxConcurrentGpu,maxConcurrentProvider,maxReservedMicros,
 maxStorageBytes,tokensPerMinute,weightedShare}
WorkerLease {tenantId,jobId,ownerId,executorFence,leaseClock:serverUtc,deadlineMs}
ProviderCircuit {profilePin,region,state:closed|open|halfOpen,
 transientFailureCount,retryAfterMs,lastProbeResult}
// 默认熔断策略候选：60秒内5个系统/传输错→open；半开只许1个廉价健康检查。
// 429遵守Retry-After；无免费健康接口不得拿付费生成当探针。
// 无权限/非法prompt/拒绝内容不计系统故障；数值需负载实验调优。
// 多租户加权deficit round-robin+租户并发/额度双门；批量短任务不得饿死长任务。
// 不在DB事务内等GPU/HTTP；失败退避入队，dead letter只带脱敏引用/错误码。
// 观察：traceId→run/plan/node/attempt/providerJob；日志只hash/计量/状态，不存素材正文。
// PostgreSQL具体版本受支持清单/依赖SBOM/SQL语义在构建前锁定；当前未测HA/吞吐。
```
