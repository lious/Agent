依赖解释：hardDeps是代码/合同产出的先后，不是“必须等所有端都实测”。同一V任务按Profile产生多条结果，只能证明被测组合；V-001/V-002/V-003/V-004/V-005的Apple结果不能放行Android。原生媒体任务另有一个“匹配当前平台的端口”条件：Apple→I-016、Android→I-017、Windows→I-018、Linux→I-019；不是这四个AND，也不能拿Apple端口满足Windows。Web走I-020独立实现，依赖已有时间/图语义与goldens不表示浏览器导入native库。实现可用fake port先测纯逻辑，但真实成片退出M0b须有匹配P0端口与真实codec/clock/storage证据。

个人单人顺序按M0a→M0b优先；独立V可在等待构建或借测期间进行，不给87项估计求和作交付承诺。每项估计假设熟悉该技术、每天8小时且设备/工具已获许可可用；学习、迁移既有工程、供应商等待、审核、设备排队及质量返工未包含。3–5人日的验证是有界spike并给go/no-go，不保证在该时限解决模型转换或画质；超时交失败证据与替代，不标功能实现完成。
