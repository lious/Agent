| 行为/状态 | 权威边界与补偿 |
| --- | --- |
| 权益与本地模型许可 | 编辑功能权益、模型下载权、模型权重商业许可、素材授权、云点数是四类门禁；买订阅不解除YuE2/肖像/voice许可。普通本地编辑不扣云点数，本地计算仍有设备/分发成本。商业模型/组件许可缺口默认风险放行不代表已获授权；未安装/不支持能力不能因已付款显示可用。 |
| 离线缓存 | 非消耗本地功能在已验证缓存政策内可用；默认保守7天订阅离线lease且不超过已知expiresAt，为产品策略而非商店保证。可信签名、单调计时与已知服务时间检查回拨；unknown不新发付费云任务，允许重试验证/恢复购买。永久本地买断缓存无订阅到期，但已知退款撤销立即生效；离线无法获知远端即时退款不得谎称实时撤销。 |
| 重放/崩溃 | 交易store+app+transactionId（Play purchaseToken受控标识）唯一；重复通知返回同交付receipt。成功交付后finish/ack失败重试确认不再发点；网络未知只查询对账。未验证/用户取消零授予。消费点充值与云任务reserve/settle/release分账，已花费用不因UI取消伪装退款。 |
| 执行前告知 | 选工具/付费素材就展示限制；ExportPreflight枚举完整渲染闭包所需权益、字体/素材、分辨率与水印，不到导出末尾才拦截。缺权益允许移除/替换或购买，不后台替用户付款。源/模板/计划/报价改变，disclosureHash与批准失效；原作品不删除。 |
| 经济模型 | 贡献=实际结算净收入−供应商全部尝试成本−存储/流量−退款/欺诈损失−可分摊服务成本；记录每满意交付的平均尝试次数。预算按币种分账，不假定API成功=用户满意。供应商/租户日限额、并发和总kill switch在gateway，不能用“不限量AI”掩盖成本。 |
| 跨端商店 | Apple StoreKit2、Google Play Billing各adapter；Windows/macOS直销/Web只在选定支付渠道/地区规则后启用，不能照搬移动IAP或默认第三方网页引导付费。实际SDK精确版本、SKU配置、地区政策与sandbox fixture为发布gate，不声称已接通。 |
