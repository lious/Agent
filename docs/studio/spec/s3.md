## 3 · 时间线编辑：每个操作必须有算法、事务与反例

以下数值均为合成30fps帧单位：A timeline[0,150) source[30,180)；B [150,300) source[60,210)；C [300,450) source[0,150)；三份源各360帧，rate=1。生产命令使用Q秒。所有写先plan→validate→preview→CAS commit；失败不半提交。

```text
EditCommand {
 id, namespace, projectId, sequenceId, actorId, origin: user|agent,
 expectedRevision, idempotencyKey, inputHash, gestureGroupId?,
 selectionIds[], readSet:[{entityId,version,fieldPaths[]}],
 writeSet:[{entityId,fieldPaths[]}], payload: ClosedCommandUnion,
 approvalId?, issuedAt, cancelEpoch
}
CommandResult {disposition:applied|noDocumentChange, commandId, previousRevision, revision, eventSeq,
 beforeImageRef, afterImageRef, inversePatchRef, invalidatedRanges:[{sequenceId,range}], warnings[]}
TimelineEditor.plan(snapshot, command) -> EditPlan
TimelineEditor.validate(plan, capabilities, locks) -> ValidatedPlan | StudioError
CommitCoordinator.commit(plan, expectedRevision, receiptKey) -> CommandResult
// 同key同inputHash返回原receipt；同key异hash拒绝。
// 先校验全部联动轨，再单SQLite事务写文档投影、Revision、Command、事件和receipt。
// 原文件/Blob永不原位修改。每次手势松手一条Command，不逐pointer写数据库。
```

| 普通删除 / 波纹删除 | DeleteSelection{ids,mode:lift\|ripple,range:null\|Range,rippleTrackIds}；删除键默认lift，波纹需专门按钮。 | lift用Gap占原位置，sequence末端可重算。ripple首版只接受单个连续R=[a,b)；对每参与轨裁掉R内、保留两侧，R之后start-=b-a，跨界split；caption同样裁切/移动。多段删除按从右到左若干命令组明确预览；未参与轨不动。 | R=[120,180)：A剩[0,120)，B剩[120,240) source[90,210)，C[240,390)，总390；锁定同步轨→全拒绝。 |

| roll | 选邻接切点双边trim手柄。Roll{leftId,rightId,delta:Q}。 | 仅连续邻片，线性rL/rR：左duration+=δ、sourceDuration+=rLδ；右start+=δ、duration-=δ、sourceStart+=rRδ、sourceDuration-=rRδ。两者外端和总时长不变；左右duration>0且handle足；现有转场随cut移动后重验。链接音频同切点按各自源速率处理。 | A/B cut150→165：A d165 source[30,195)，B start165 d135 source[75,210)；总450，C不动。 |

| 统一错误码 | UI/重试/事务结果 |
| --- | --- |
| REVISION_CONFLICT / READSET_STALE / FIELD_LOCKED | 保留候选，展示冲突字段/当前revision；只有重新plan并再次预览才可提交。不能自动重试覆盖写。 |
| SOURCE_OUT_OF_RANGE / TRANSITION_HANDLE_SHORT / COLLISION / SYNC_LOCKED | 命令无写；ghost变红并显示可用边界。UI拖动可实时clamp用于预览，但最终命令必须提交被clamp后的精确参数并让用户看见；AI调用默认拒绝而非偷偷修正。 |
| MISSING_MEDIA / UNSUPPORTED_PROFILE / COLOR_POLICY_REQUIRED | 工程可打开并列缺失/不支持项；禁止默认最终导出。用户可relink、明确以代理导出、选择归一解释；不私自上传转码。 |
| CANCELED / ALREADY_COMMITTED / RESOURCE_BUSY / DISK_FULL | CANCELED未commit则无revision；已commit必须另undo；资源忙排队有可见状态；磁盘满保旧包和journal，清理未引用缓存后同save job恢复，不自动删源片。 |
| APPROVAL_STALE / BUDGET_EXCEEDED / REMOTE_ACCEPTANCE_UNKNOWN | 批准不匹配重新展示；超预算不发请求；受理未知锁住reservation并查账，不能把超时当失败重付。所有错误记录correlationId与已执行/未执行边界。 |

补充规则：timeline移动/波纹必须显式列出参与轨ID，UI默认是targeted轨与syncLock轨的并集，AI不得自行扩大范围。锁定的同步轨若被要求移动就整体拒绝，并允许用户取消同步锁后重新预览。标记分sequence绝对与clipLocal两种；rippleMarkers=false的绝对marker不移动，true则按同一区间变换，R内marker在extract时随删除进入逆补丁。字幕默认clipLocal随镜头；跨删除区间的cue裁切，多段保留拆成两cue且文字不重写。

实现文件与测试：edit_algebra.dart实现纯函数，不读DB；command_planner.dart展开链接/组/轨道集合；range_index.dart使用按start排序的平衡区间索引，交集查询O(logN+K)；tests/nle/trim_test.dart逐条对应上表。每个fixture还要断言：源hash不变、总时长正确、外键无悬挂、undo后canonical document内容hash等于before（revision/审计字段除外）、失败时receipt与revision不变。大多选move不允许O(帧数)遍历，只处理相交项和下游范围。
