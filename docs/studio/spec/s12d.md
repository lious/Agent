## 12D · 国际化、无障碍与隐私诊断

| 类/接口 | 字段/状态与可执行验收 |
| --- | --- |
| LocaleCatalog/FontResolver | UI用稳定messageKey+typedArgs，不拼接已翻译碎片；英文与简中为首个文案集，市场新增语言单独验收。日期/币种本地化不改变Q时间/原事实；CJK/韩文/emoji/RTL用固定glyph/字体fallback与bidi整形。项目字幕可多独立语言轨，语言不是用户地区；未选翻译模型不自动翻译。 |
| EditorSemantics | SemanticNode{id,role,labelKey,valueText,enabled,actions[]}；时间线替代列表按track/order/PTS排列，每Clip暴露选择、跳入点、精确in/out时间输入、前后移一帧/音频sample、轨道锁与错误说明；Layer提供上下移/数值transform/修边按钮，不要求捏合拖拽才可操作。焦点在取消/完成后回原控件，不因晚到AI结果抢焦点。 |
| A11yPolicy | 读屏VoiceOver/TalkBack与桌面键盘/屏幕阅读器；触控目标初始至少48逻辑单位，字号200%及长标签仍能确认/取消；对比目标WCAG AA文本4.5:1（大字按其例外），不可仅红绿/颜色传错误。减少动态效果停自动播放/闪烁预览，进度只播报阶段不逐token刷屏；不把UI减少动画等于删成片运镜。 |
| DiagnosticExporter | 默认本机ring为结构化字段白名单：opaque run/job/command ID、pack/operator/build版本、阶段/errorCode、粗设备档、耗时/峰值/thermal摘要；默认7天/5MiB环形上限是产品策略。排除正文/CoT/音视频/源路径/文件名/EXIF GPS/人物embedding/secret/签名URL/store token。用户预览导出清单、脱敏后另选目标，上传另授权。 |
| Crash/Analytics | CrashSDK/analytics默认为未接入；未来引入需App隐私/SDK清单/数据最小化/适用地区同意及关闭开关。崩溃栈也可能含路径/参数，sanitize通过再发送；无法证明脱敏则留本地不发。删除会话/source/voice时清相关诊断正文队列，不以“调试”复活。 |
| 测试 | 语义树快照、键盘Tab/焦点、200%字号、RTL/CJK/emoji换行/字体缺字、字幕安全区/烧录回读；diag放合成email/GPS/token/filePath作为canary，导出不得出现。真机读屏与用户可用性仍须人工测试，不能靠字符串存在即通过。 |
