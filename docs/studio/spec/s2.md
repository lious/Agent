## 2 · 时间、帧、sample与可持久化NLE模型

所有区间半开。全局只用精确有理秒Q，不用double秒、毫秒或29.97近似值当真相。第k帧时间t=k×fps.d/fps.n，48k音频第m sample时间m/48000。视频编辑边界落sequence帧格；音频独立trim可落sample格，显示“子帧”。音频跨轨与video同步不强行四舍五入到视频帧。Drop-frame timecode只改变显示编号，不删媒体帧。

```text
// packages/studio_document/lib/src/time.dart — 规范接口（拟实现）
Q add(Q a,Q b); Q sub(Q a,Q b); Q mul(Q a,Q b); int compare(Q a,Q b);
Q quantize(Q t, FrameRate fps, Rounding mode); // ties-to-even，仅命令入口一次量化
int frameIndex(Q t, FrameRate fps, Rounding mode);
BigInt sampleIndex(Q t,int sampleRate,Rounding mode);
Range? intersect(Range a,Range b); bool overlaps(Range a,Range b);
Q sourceAt(Clip c,Q timelineT); // s0 + f(timelineT-c.timelineRange.start)
// 300帧@30000/1001 = 10.01秒，不是10秒。
// 帧k所覆盖的音频samples： [round(k*Fs/fps), round((k+1)*Fs/fps))
// 不能每帧都加round(Fs/fps)，否则累计音画漂移。
```

数量与唯一性：Project 1:N Sequence/Asset/ImageDocument/Session；Sequence 1:N Track，Track 1:N Clip/Gap；同一AssetVersion可被N个Clip引用。一个生成Job生产0..N Candidate，每个Candidate可被N个Clip放置；生成结果不等于TimelineRevision。Effect和Caption都有独立version，不能因替换视频Asset而复写字幕text。所有media/data/blob引用由引用边表管理；refCount只是缓存。

Schema策略：项目schema major控制破坏性迁移；本页定义2.0.0完整合同，原1.0.0合成例需纯数据迁移后读取。minor只允许已声明扩展点中的可忽略内容，不绕过additionalProperties:false给闭合实体加必填字段；requiredFeatures声明不可忽略能力。未知extensions按JSON原样保存，不能执行其中脚本。reader低于minReader或缺必需能力→只读并提供可移出归档，不静默丢效果。生产schema用JSON Schema 2020-12、additionalProperties:false（明确声明的extensions及vendor parameters数据容器除外），Q用pattern校验整数串，数值跨字段关系由DocumentValidator执行。
