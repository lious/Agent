## 12A · 真本地LLM验收与资源控制合同

CanonicalContext不是聊天SDK的session。8A的MessageEnvelope只管附件内容顺序，不足以表达Harness的角色/调用关系；新增以下HarnessMessage包裹contentEnvelopeRef，不修改既有附件Schema/工程2.0。字段全部required、闭合、可空显式null；ID/Namespace/U64/ProfilePin沿既有类型。正文引用存在Session私有库，能清空而保最小无正文事件头。

```text
HarnessMessage {schemaVersion:"1.0.0",namespace,id,sessionId,branchId,turnId,
 runId:Id|null,role:system|user|assistant|tool,agentId:Id|null,
 modelProfilePin:ProfilePin|null,toolCallId:Id|null,projectRevision:U64|null,
 contentEnvelopeRef:Id|null,status:draft|streaming|complete|failed|redacted,
 recordVersion:U64,privacyEpoch:U64}
MessageStore.append(message,expectedBranchHead,expectedPrivacyEpoch)->MessageReceipt
MessageValidator.validate(message,scope,liveCalls,contentGrants)->Valid|MessageError
ProviderMessageCompiler.compile(canonicalContext,profilePin)->ProviderMessages
// system仅App签名配置生成；用户附件/OCR/工具结果内写role=system不改变信任级。
// session/branch/turn/run都必须存在且同namespace，并满足父关系；不能凭ID读其他App。
// tool角色须run/toolCallId/agentId非null且匹配waiting的调用；user角色toolCallId=null。
// assistant绑定实际modelProfilePin，tool不冒充assistant；provider模板的system折叠
// 等差异在adapter处理，若不能保持信任边界则该profile不开放工具执行。
// complete仅由stream终结且解析/校验后产生；半截tool JSON不能成为ToolReady。
// redacted时contentEnvelopeRef=null；其余有正文状态引用有效的8A MessageEnvelope。
// MessageStore与branch head CAS同Session DB事务；正文purgе、FTS/cache作失效epoch，
// 发送前复核privacyEpoch；较早stream晚到只记无正文终态，不还原引用。
// MESSAGE_SCOPE_MISMATCH/TOOL_CALL_MISMATCH/UNTRUSTED_SYSTEM/STALE_PRIVACY_EPOCH
// 拒绝且不调用模型/工具。删除/导出规则仍以10A/5D为准，不默存provider reasoning。

```

真实交付要以飞行模式、本机素材、未硬编码同义指令完成“导入→智能选区→修边→图层/模板→保存重开→导出”和“视频5..20秒→ASR字幕→人工校字→导出”；只聊天、脚本或按钮不算本地Agent。目标资源不足时先缩scope/模型profile/排队，显式显示冷加载和能力降低；不自动转云。当前没有任一机型实测成功率、RAM或速度。多Agent异构与独立Harness继续为核心，不恢复旧单协调器产品范围。
