## 10B · 独立Harness：运行边界、控制语义与公开依据

| 对象/权威 | 可编码合同 | 状态与用户反馈 |
| --- | --- | --- |
| Session/Branch/Thread | 沿用9节Session—Branch；Thread仅对外适配时Branch的别名，不新增另一套对话真相。Turn是一次用户目标；steer是同一Turn上的新MessageEnvelope/有效意图事件，不改旧正文。Run是一个Agent/模型配置在该Turn中的执行；模型一次往返是Iteration，不另造Turn。 | TurnView由排队控制意图、Run及待审批推导，不单独存可冲突的status。分支与工程revision分离。 |
| Run/Step/Job | Run沿用9节id；10I的h_runs是它的运行状态存储，不是第二个Run。Step=(planId,version,nodeId)，每次attempt有独立ToolCall；Job是外部服务/端侧媒体执行器工作句柄，不等于一次LLM调用。 | Run：queued→running→waitingApproval/waitingExternal/paused/needsReview→succeeded/failed/cancelled；interrupt经pausing到paused，cancel经cancelling到cancelled。waitingExternal仍需对账，不等于失败。 |
| Step/状态合法边 | pending→ready→leased→running；缺审批→waitingApproval；已受理异步→waitingExternal；可重试暂错→retryWait→ready；终态succeeded/failed/cancelled/skipped；缺证据或不可判定→needsReview。 | 终态不可原地复活。修复生成新plan版本/新Step身份；纯重试attempt递增，不能重置预算。运行中资源丢失可暂停，不能把未完成步骤标成功。 |
| queue/steer | ControlIntent(queue)分配新Turn排队；steer要求expectedTurnId和expectedPlanVersion匹配活动Turn，追加有效意图版本，停止旧模型流并重编受影响子图。 | steer不隐式取消已提交付费服务；旧Job先对账，结果只进候选/隔离区。旧图未提交审批失效；新图新prompt/资源/费用重新确认。显示“调整已接收，正在收束旧任务”。 |
| interrupt/withdraw/cancel | interrupt仅暂停调度，在可检查点边界停止本地工作；withdraw只撤回尚未应用的queue/steer控制，不等于删除消息/素材。cancel递增Run.cancelEpoch并停止新派发，给支持取消的Job发best-effort请求。 | 暂停≠退款；取消≠GPU立即退出。已接收/未知付费Job继续只读对账。删除会话/素材走10A删除屏障，不能用withdraw绕过。 |
| UI/持久化边界 | 用户操作先写Session intent outbox，再幂等送workspace runtime；runtime ack后才能显示“已生效”。Run/Step运行真相在workspace，Session DB仅保存会话正文、控制意图与可重建Run投影。 | 跨库无分布式原子事务：崩溃重放同intentId；未ack显示“指令待处理”，不能显示已取消成功。隐私删除先落Session真相并关闭发送闸，恢复完成跨库epoch同步前不发模型/工具请求。 |

```text
// dart/packages/harness_runtime；媒体像素/采样执行仍由C++内核与各端适配器负责
interface HarnessRuntime {
 accept(ticket: RunStartTicket): Future<RunReceipt>; // ns/turn/branch/intentRef/inputHash/epoch/TTL
 control(intent: ControlIntent): Future<ControlReceipt>; // id相同+hash相同幂等；异hash拒绝
 resume(runId: Id, expectedRecordVersion: I64String): Future<RunReceipt>;
 subscribe(ns: Namespace, runId: Id, afterSeq: I64String): Stream<RuntimeEvent>;
}
interface PlanCompiler { compile(intentSnapshot, registeredHandlers, capabilityPins): Result<PlanGraph>; }
interface DurableScheduler { claimReady(ns, lane, owner, clock): Result<StepLease?>; }
interface TurnInterpreter { advance(runLease, inputSnapshot): Future<StepOutcome>; }
interface ContextCompiler { build(scope, deletionBarrier, tokenBudget, tokenizerPin): ContextSnapshot; }
// 顺序不可被Prompt/Skill/模型响应改变；没有任意SQL/shell/file-path执行入口。
async tick(ns):
  recoverPrivacyBarrierOrBlockSend(ns)
  applyControlInboxInSeqOrder() // 删除/撤销权限先于cancel，再于普通steer/queue
  reconcileAcceptedAndUnknownJobs() // 无新付费；账务和候选可用性分别处理
  run = claimRunWithFenceOrReturn()
  if stopRequested(run): checkpointAndAcknowledgeAtSafeBoundary(); return
  graph = loadPinnedGraph(); validateGraphAndEffectiveEpochs(graph)
  lease = claimEligibleStepAndResourceBudgetAtomically(graph)
  if noLease: deriveWaitingStateOrDependencyDeadEnd(); return
  if lease.kind == model:
    ctx = ContextCompiler.build(latestIntent, latestPrivacy, remainingParentBudget)
    request = requestFrom(ctx, pinnedTools)
    preparedModel = ToolGateway.prepareModel(request, lease) // token费用/上下文上传同样审批
    stream = ToolGateway.dispatchModelStream(preparedModel, cancellationToken)
    // 内部才调ModelProvider.generate；未过policy/quote/approval/epoch gate绝不进入Provider。
    for event in stream:
      rejectStaleIterationOrPrivacyEpoch(event)
      boundedAssembler.consume(event) // 不把部分tool JSON当可执行命令
    outcome = validateTypedModelOutputOrOneBoundedRepair()
  else:
    prepared = ToolGateway.prepare(lease) // 10D；不含网络/付费副作用
    outcome = await ToolGateway.dispatchOrWaitApproval(prepared)
  validateOutputSchemaAndEvidence(outcome)
  CAS_publishStepOutcome(lease.fence, lease.planPin, cancelEpoch, privacyEpoch,
                         rightsEpoch, inputHash, dependencyHashes)
  appendEventAndResultOutboxInSameWorkspaceTransaction()
  yieldToUI() // 不在Dart UI isolate忙等；本地执行器在worker isolate/native线程
// 每次循环先检查预算/死循环/控制输入；Step成功不代表Proposal已接受或工程已保存。
```
