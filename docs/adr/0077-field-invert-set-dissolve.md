# ADR 0077 — Field-aware invert of a prior SetDissolve command

## Status

Accepted for Increment 1.70 as a bounded slice of the original I-005 remaining work on the field-aware invert matrix (s3 / s5a). I-005 and I-010 remain partial. This increment does not claim a complete invert matrix. Official InversePatch `kind` stays `restoreSnapshot`. Linear undo/redo stay tip snapshot restores. Already-delivered RippleDeleteClips, RippleTrimClip, leave-gap TrimClip, leave-gap DeleteClip, MoveClip / MoveClips (including reject, overwrite, and insert modes, and includeLinks=false), LiftClips/Cut, SplitClip, ExtractAudioClip, UnlinkAudioVideo / LinkAudioVideo, SetAudioTrackState, SetTrackState locked/unlock, overwrite PasteClips, and insert PasteClips semantics stay unchanged. The single-clip Move button stays `MoveClip` and does not silently take an unlinked audio partner or expand into a group move. Captions still do not enter the internal clipboard package. The OS clipboard stays closed. Video and caption mute/solo stay refused at admission with `FEATURE_NOT_IMPLEMENTED`; audio muted/solo stay `SetAudioTrackState`; `syncLock` is not toggled. This increment does not open auto-close as a MoveClips mode, or open new-track, cross-project bake, source-interval crop, marker sidecar formats, mid-clip insert paste invert, RemoveDissolve invert, or I-006. A diverging unlink invert remains `LINK_OFFSET_MISMATCH`. Invert's version indexer continues to skip source refs (`streamId` present). Leaf-level rational `n`/`d` granularity is unchanged. This slice does not change field-invert list insertion order or retarget `IMPLICIT_GAP`. An overwrite that would uncover or crop a source cue remains `ANCHOR_OUT_OF_RANGE`. An overwrite that would overlap a followed cue and a dest remnant remains `CAPTION_OVERLAP`. A topology edit of a dissolve host remains `TRANSITION_RANGE_EDIT_REQUIRES_REMOVAL`.

## Context

Increment 1.69 officially admitted invert of a prior non-tip insert-mode `PasteClips`. `SetDissolve` was already the admitted VIDEO linear dissolve on an adjacent cut, with exact frame-grid handles and missing-handle rejection. It had not been qualified as an invert-matrix target on a persist path with captions present. Sequence definition fingerprints already close transition children that live outside the sequence object, the same way they close captions. Invert previously minted a new sequence version only when captions or markers changed, so a persist-path invert of SetDissolve after a later marker edit reused the post-marker sequence version with the dissolve removed and refused `IMMUTABLE_VERSION_CONFLICT`.

A later leave-gap `MoveClip` of a dissolve host is not this slice's official conflict path, because that topology edit is refused with `TRANSITION_RANGE_EDIT_REQUIRES_REMOVAL` while the dissolve still exists. Official conflict is invert of the tip, or a later `SetDissolve` rewrite of the same pair that changes the recorded handles.

## Decision

Officially admit invert of a prior committed `SetDissolve` of a left remnant onto the adjacent right remnant at the 1s cut, with 6-frame (1/5s) handles, that is not the undo tip. Only that command's dissolve write set is restored when those fields still match the command's after-image. A later unrelated `SetMarkers`, a later text edit of the followed stay cue, or a later text edit of the unmoved hello cue, therefore does not conflict: invert removes the dissolve, keeps both remnants' starts and the sequence duration, keeps the followed stay cue and the unmoved hello cue, and keeps the later markers and revised text. A later `SetDissolve` rewrite of the same pair, or invert of the tip, is whole-group `UNDO_CONFLICT` and does not roll the database back.

Invert's post-apply version bump now also mints a new sequence version when clock-stripped `transitions` change, because those children are already part of the sequence definition fingerprint. This does not change production edit algebra, insertion order, or `IMPLICIT_GAP`, and does not retarget existing refusal codes.

Official workbench path splits at 1s, adds hello and stay cues, selects the left remnant, sets a 6-frame VIDEO dissolve, and a later marker — not the single-clip Move button; extract is not required. Mid-clip insert paste invert, RemoveDissolve invert, and auto-close are not this slice's official success path. Captions and markers are not burned into preview or MP4; export stays a VTT sidecar.

## Consequences

I-005 and I-010 stay partial. The field-aware invert matrix now has an official persist path for SetDissolve after later markers or later cue text edits, alongside the already-delivered invert paths through insert-mode PasteClips. RemoveDissolve invert, mid-clip insert paste invert, invert of a non-last RippleDeleteClips / leave-gap DeleteClip / LiftClips, auto-close-on-move, new-track, cross-project bake, OS clipboard, source-interval crop, marker sidecar formats, MP4 burn-in, video/caption mute/solo, `syncLock`, the table's 0.02s off-grid offset, and I-006 remain out of this slice.
