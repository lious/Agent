# ADR 0087 — Field-aware invert of a prior ripple-trim-lengthen command

## Status

Accepted for Increment 1.80 as a bounded slice of the original I-005 remaining work on the field-aware invert matrix (s3 / s5a). I-005 and I-010 remain partial. This increment does not claim a complete invert matrix. Official InversePatch `kind` stays `restoreSnapshot`. Linear undo/redo stay tip snapshot restores. Already-delivered RippleDeleteClips (clip-id, rightmost), range ripple-close, RippleTrimClip shorten, leave-gap TrimClip, leave-gap DeleteClip, MoveClip / MoveClips (including reject, overwrite, and insert modes, and includeLinks=false), LiftClips/Cut, SplitClip, ExtractAudioClip, UnlinkAudioVideo / LinkAudioVideo, SetAudioTrackState, SetTrackState locked/unlock, overwrite / insert PasteClips, SetDissolve, RemoveDissolve, SetOpacityKeyframe, RemoveOpacityKeyframe, SetClipOpacity, SetClipTransform, SetClipCrop, SetClipColorBasic, and SetMasterAudio invert semantics stay unchanged. The Increment 1.79 invert-path gap insertion stays unchanged: in-place field restores run first, then a missing track gap is inserted by timeline start; media clips still append, so invert of a non-trailing leave-gap delete, LiftClips, or mid-span insert paste still refuses `IMPLICIT_GAP`. The single-clip Move button stays `MoveClip` and does not silently take an unlinked audio partner or expand into a group move. Captions still do not enter the internal clipboard package. The OS clipboard stays closed. Video and caption mute/solo stay refused at admission with `FEATURE_NOT_IMPLEMENTED`; audio muted/solo stay `SetAudioTrackState`; `syncLock` is not toggled. This increment does not open auto-close as a MoveClips mode, or open new-track, cross-project bake, source-interval crop, marker sidecar formats in this checkout, mid-clip insert paste invert, or I-006. A diverging unlink invert remains `LINK_OFFSET_MISMATCH`. Invert's version indexer continues to skip source refs (`streamId` present). Leaf-level rational `n`/`d` granularity is unchanged. An overwrite that would uncover or crop a source cue remains `ANCHOR_OUT_OF_RANGE`. An overwrite that would overlap a followed cue and a dest remnant remains `CAPTION_OVERLAP`. A topology edit of a dissolve host remains `TRANSITION_RANGE_EDIT_REQUIRES_REMOVAL`. A later same-time keyframe after removal still refuses `DUPLICATE_KEYFRAME` and is not retargeted. Invert still mints a new sequence version when clock-stripped `transitions`, `effects`, or `audioBuses` change, and still mints new clip and sequence versions when a clip's referenced effects are already in the bump set. Marker sidecar implementation is not in this checkout. Production edit algebra is unchanged in this increment. This slice does not reopen or change the already-delivered ripple-close invert path except as an unchanged regression.

## Context

Increment 1.79 officially admitted invert of a prior non-tip range ripple-close. Increment 1.59 already admitted invert of a prior non-tip `RippleTrimClip` shorten (negative Δ). Lengthen — `RippleTrimClip` with positive Δ, workbench 「Ripple trim out/in lengthen」 — was already the admitted grow-and-shift form of the same command, and is not a fourth MoveClips mode. That sign had not been qualified as an invert-matrix target on a persist path with captions present. Official later work is a marker or a text edit, not a later `SetMasterAudio`, `SetClipColorBasic`, leave-gap trim of a remaining remnant, a later ripple-close, or a later move as success. Official conflict is invert of the tip, or a later same-kind rewrite of the same remnant that is a real write-set conflict.

After a 1s split of a 3s clip, the right remnant already uses source through the stream end, so official out-point lengthen is applied to the left remnant, which still has unused later source. The later stay cue is clipLocal on the right remnant and follows the dest shift; hello stays unmoved on the left remnant.

## Decision

Officially admit invert of a prior committed `RippleTrimClip(left, 'out', Q.of(1))` that is not the undo tip. Only that lengthen command's still-matching write set is restored: left duration returns to 1, later content moves back (right start returns to 1, stay follows back to 1.5), sequence duration returns to 3, and the unmoved hello stays at 0. A later unrelated `SetMarkers`, a later text edit of the followed stay cue, or a later text edit of the unmoved hello cue, therefore does not conflict and is kept. Invert of the tip, or a later second out-lengthen of the same left remnant to duration 3, is whole-group `UNDO_CONFLICT` and does not roll the database back.

Official workbench path splits at 1s, adds hello and stay cues, selects the left remnant, leaves edit-frames at 30, applies 「Ripple trim out lengthen」, and a later marker. Extract is not required. Mid-clip insert paste invert and auto-close as a MoveClips mode are not this slice's official success path. Captions and markers are not burned into preview or MP4; export stays a VTT sidecar. Persist-path checks after archive/fork use caption text and anchors, the later marker label, remnant start times 0 and 1, the duration of the remnant that starts at 0s (1) and of the remnant that starts at 1s (2), and sequence duration 3, not pre-fork clip ids.

This slice keeps the Increment 1.73 and 1.78 invert version bumps and the Increment 1.79 invert-path gap insertion. Persist-path invert after later markers already minted a new sequence version because clocksOff of the sequence object changes, and needed no further bump and no further production change. `IMMUTABLE_VERSION_CONFLICT` is not retargeted. Production edit algebra, insertion order, `IMPLICIT_GAP`, `SOURCE_OUT_OF_RANGE`, and `CLIP_TOO_SHORT` are unchanged.

## Consequences

I-005 and I-010 stay partial. The field-aware invert matrix now has an official persist path for ripple-trim-lengthen after later markers or later cue text edits, alongside the already-delivered invert paths for RippleTrimClip shorten, range ripple-close, SetMasterAudio, and the earlier visual, dissolve, paste, move, and topology commands. Mid-clip insert paste invert, invert of a non-last RippleDeleteClips / leave-gap DeleteClip / LiftClips, auto-close-on-move, new-track, cross-project bake, OS clipboard, source-interval crop, marker sidecar formats in this checkout, MP4 burn-in, video/caption mute/solo, `syncLock`, the table's 0.02s off-grid offset, and I-006 remain out of this slice.
