# ADR 0079 — Field-aware invert of a prior SetOpacityKeyframe command

## Status

Accepted for Increment 1.72 as a bounded slice of the original I-005 remaining work on the field-aware invert matrix (s3 / s5a). I-005 and I-010 remain partial. This increment does not claim a complete invert matrix. Official InversePatch `kind` stays `restoreSnapshot`. Linear undo/redo stay tip snapshot restores. Already-delivered RippleDeleteClips, RippleTrimClip, leave-gap TrimClip, leave-gap DeleteClip, MoveClip / MoveClips (including reject, overwrite, and insert modes, and includeLinks=false), LiftClips/Cut, SplitClip, ExtractAudioClip, UnlinkAudioVideo / LinkAudioVideo, SetAudioTrackState, SetTrackState locked/unlock, overwrite / insert PasteClips, SetDissolve, and RemoveDissolve semantics stay unchanged. The single-clip Move button stays `MoveClip` and does not silently take an unlinked audio partner or expand into a group move. Captions still do not enter the internal clipboard package. The OS clipboard stays closed. Video and caption mute/solo stay refused at admission with `FEATURE_NOT_IMPLEMENTED`; audio muted/solo stay `SetAudioTrackState`; `syncLock` is not toggled. This increment does not open auto-close as a MoveClips mode, or open new-track, cross-project bake, source-interval crop, marker sidecar formats, mid-clip insert paste invert, RemoveOpacityKeyframe invert, SetClipOpacity invert, or I-006. A diverging unlink invert remains `LINK_OFFSET_MISMATCH`. Invert's version indexer continues to skip source refs (`streamId` present). Leaf-level rational `n`/`d` granularity is unchanged. This slice does not change field-invert list insertion order or retarget `IMPLICIT_GAP`. An overwrite that would uncover or crop a source cue remains `ANCHOR_OUT_OF_RANGE`. An overwrite that would overlap a followed cue and a dest remnant remains `CAPTION_OVERLAP`. A topology edit of a dissolve host remains `TRANSITION_RANGE_EDIT_REQUIRES_REMOVAL`. Invert still mints a new sequence version when clock-stripped `transitions` change; this slice does not retarget `IMMUTABLE_VERSION_CONFLICT`. Marker sidecar formats stay closed: the original specification has no first official format, and this slice does not invent one.

## Context

Increment 1.71 officially admitted invert of a prior non-tip `RemoveDissolve`. `SetOpacityKeyframe` was already the admitted clip-local VIDEO opacity keyframe edit (linear or hold, on-frame times). It had not been qualified as an invert-matrix target on a persist path with captions present. Official later work is a marker or a text edit, not a later `RemoveOpacityKeyframe` or a later `SetClipOpacity`. Official conflict is invert of the tip, or a later `SetOpacityKeyframe` rewrite at the same local time that changes the recorded value.

## Decision

Officially admit invert of a prior committed `SetOpacityKeyframe` of the left remnant at local time 0 with value 0.5 and linear interpolation, that is not the undo tip. Only that command's opacity-keyframe write set is restored when those fields still match the command's after-image. A later unrelated `SetMarkers`, a later text edit of the followed stay cue, or a later text edit of the unmoved hello cue, therefore does not conflict: invert removes the opacity effect from the left remnant, keeps both remnants' starts and the sequence duration, keeps the followed stay cue and the unmoved hello cue, and keeps the later markers and revised text. A later `SetOpacityKeyframe` rewrite at the same local time, or invert of the tip, is whole-group `UNDO_CONFLICT` and does not roll the database back.

Official workbench path splits at 1s, adds hello and stay cues, selects the left remnant, enters clip opacity 0.5 and local frame 0, sets a linear opacity keyframe, and a later marker — not the single-clip Move button; extract is not required. Mid-clip insert paste invert, RemoveOpacityKeyframe invert, SetClipOpacity invert, and auto-close are not this slice's official success path. Captions and markers are not burned into preview or MP4; export stays a VTT sidecar. Persist-path checks after archive/fork use caption text and anchors, the later marker label, remnant start times, sequence duration 3, and the absence of an opacity effect on either remnant, not pre-fork effect ids.

## Consequences

I-005 and I-010 stay partial. The field-aware invert matrix now has an official persist path for SetOpacityKeyframe after later markers or later cue text edits, alongside the already-delivered invert path for RemoveDissolve. RemoveOpacityKeyframe invert, SetClipOpacity invert, mid-clip insert paste invert, invert of a non-last RippleDeleteClips / leave-gap DeleteClip / LiftClips, auto-close-on-move, new-track, cross-project bake, OS clipboard, source-interval crop, marker sidecar formats, MP4 burn-in, video/caption mute/solo, `syncLock`, the table's 0.02s off-grid offset, and I-006 remain out of this slice.
