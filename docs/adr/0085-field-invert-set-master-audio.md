# ADR 0085 — Field-aware invert of a prior SetMasterAudio command

## Status

Accepted for Increment 1.78 as a bounded slice of the original I-005 remaining work on the field-aware invert matrix (s3 / s5a). I-005 and I-010 remain partial. This increment does not claim a complete invert matrix. Official InversePatch `kind` stays `restoreSnapshot`. Linear undo/redo stay tip snapshot restores. Already-delivered RippleDeleteClips, RippleTrimClip, leave-gap TrimClip, leave-gap DeleteClip, MoveClip / MoveClips (including reject, overwrite, and insert modes, and includeLinks=false), LiftClips/Cut, SplitClip, ExtractAudioClip, UnlinkAudioVideo / LinkAudioVideo, SetAudioTrackState, SetTrackState locked/unlock, overwrite / insert PasteClips, SetDissolve, RemoveDissolve, SetOpacityKeyframe, RemoveOpacityKeyframe, SetClipOpacity, SetClipTransform, SetClipCrop, and SetClipColorBasic invert semantics stay unchanged. The single-clip Move button stays `MoveClip` and does not silently take an unlinked audio partner or expand into a group move. Captions still do not enter the internal clipboard package. The OS clipboard stays closed. Video and caption mute/solo stay refused at admission with `FEATURE_NOT_IMPLEMENTED`; audio muted/solo stay `SetAudioTrackState`; `syncLock` is not toggled. This increment does not open auto-close as a MoveClips mode, or open new-track, cross-project bake, source-interval crop, marker sidecar formats in this checkout, mid-clip insert paste invert, ripple-close or ripple-trim-lengthen invert, or I-006. A diverging unlink invert remains `LINK_OFFSET_MISMATCH`. Invert's version indexer continues to skip source refs (`streamId` present). Leaf-level rational `n`/`d` granularity is unchanged. This slice does not change field-invert list insertion order or retarget `IMPLICIT_GAP`. An overwrite that would uncover or crop a source cue remains `ANCHOR_OUT_OF_RANGE`. An overwrite that would overlap a followed cue and a dest remnant remains `CAPTION_OVERLAP`. A topology edit of a dissolve host remains `TRANSITION_RANGE_EDIT_REQUIRES_REMOVAL`. A later same-time keyframe after removal still refuses `DUPLICATE_KEYFRAME` and is not retargeted. Invert still mints a new sequence version when clock-stripped `transitions` or `effects` change, and still mints new clip and sequence versions when a clip's referenced effects are already in the bump set. Marker sidecar implementation is not in this checkout. Production edit algebra is unchanged in this increment.

## Context

Increment 1.77 officially admitted invert of a prior non-tip `SetClipColorBasic`. `SetMasterAudio` was already the admitted master bus write (`gainDb`, `pan`, `muted`, `solo`, validated by `AudioBus`). Default parameters are `gainDb` 0, `pan` 0, `muted` false, and `solo` false; the official first command is a non-default already-admitted master gain of -6 dB, matching the existing workbench control. That command had not been qualified as an invert-matrix target on a persist path with captions present. Official later work is a marker or a text edit, not a later `SetClipColorBasic`, `SetClipCrop`, `SetClipTransform`, `SetClipOpacity`, `SetOpacityKeyframe`, or `RemoveOpacityKeyframe`. Official conflict is invert of the tip, or a later `SetMasterAudio` rewrite that changes the recorded parameters, because that rewrite is a real write-set conflict on the same master bus fields.

Sequence fingerprints already close the resolved audio bus even though `audioBuses` live outside the sequence object. Persist-path invert after a later marker therefore has to mint a new sequence version when clock-stripped `audioBuses` change; otherwise invert would reuse the post-marker sequence version and hit `IMMUTABLE_VERSION_CONFLICT`. That code is not retargeted.

## Decision

Officially admit invert of a prior committed `SetMasterAudio(gainDb: -6)` that is not the undo tip. Only that command's still-matching master-audio write set is restored. A later unrelated `SetMarkers`, a later text edit of the followed stay cue, or a later text edit of the unmoved hello cue, therefore does not conflict: invert restores default master gain 0 (pan 0, muted false, solo false), keeps both remnants' starts and the sequence duration, keeps the followed stay cue and the unmoved hello cue, and keeps the later markers and revised text. Invert of the tip, or a later `SetMasterAudio` rewrite to `gainDb: -12` that conflicts on the same write set, is whole-group `UNDO_CONFLICT` and does not roll the database back.

Official workbench path splits at 1s, adds hello and stay cues, enters master gain -6 dB on the existing `master-gain-db` control, saves persisted master audio, and a later marker — not the single-clip Move button; extract is not required. Mid-clip insert paste invert, ripple-close or ripple-trim-lengthen invert, and auto-close are not this slice's official success path. Captions and markers are not burned into preview or MP4; export stays a VTT sidecar. Persist-path checks after archive/fork use caption text and anchors, the later marker label, remnant start times, sequence duration 3, and restored default master gain, not pre-fork bus or effect ids.

This slice keeps the Increment 1.73 invert version bump, and extends it in the same bounded way: invert also mints a new sequence version when clock-stripped `audioBuses` change. Production edit algebra, insertion order, and `IMPLICIT_GAP` are unchanged. `IMMUTABLE_VERSION_CONFLICT` is not retargeted.

## Consequences

I-005 and I-010 stay partial. The field-aware invert matrix now has an official persist path for SetMasterAudio after later markers or later cue text edits, alongside the already-delivered invert paths for SetClipColorBasic and the earlier visual, dissolve, paste, move, and topology commands. Mid-clip insert paste invert, invert of a non-last RippleDeleteClips / leave-gap DeleteClip / LiftClips, ripple-close or ripple-trim-lengthen invert, auto-close-on-move, new-track, cross-project bake, OS clipboard, source-interval crop, marker sidecar formats in this checkout, MP4 burn-in, video/caption mute/solo, `syncLock`, the table's 0.02s off-grid offset, and I-006 remain out of this slice.
